Buy in stages

Decide the room now. Furnish it over time.

1 / Lock the essentials

Confirm the layout, sofa size and fabric. Prioritize one sofa and a practical table for move-in, subject to the existing $25,000 allowance covering essentials across several rooms.

2 / Complete the seating

Add the pair of chairs, correctly sized rug and reachable side table. If buying upholstery later, record the fabric specification and expect dye-lot or availability changes; keep a physical sample.

3 / Finish the room

Install the selected art, lamp, plant and a few accessories. Coordinate fitted cabinets separately with the contractor. Avoid counting their cost twice as both construction and furniture.

The finished-room proposal does not increase the move-in budget. A priced schedule follows exact configuration and measured fit. No order or contractor release has been made.
